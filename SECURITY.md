# Security policy

Advantec Global Services takes the security of our software and our clients seriously. If you believe you have found a vulnerability in any repository in this organization, we want to hear from you.

## Reporting a vulnerability

Please do not report security vulnerabilities through public issues, discussions, or pull requests.

Instead, use one of these channels:

- **GitHub private vulnerability reporting** — on the affected repository, open the Security tab and choose "Report a vulnerability". This is our preferred channel.
- **Email** — security@agsi.us

Include as much of the following as you can:

- The repository and version or commit affected
- A description of the issue and its potential impact
- Steps to reproduce, or a proof of concept
- Any suggested remediation

## What to expect

- We will acknowledge your report within 3 business days.
- We will keep you informed as we investigate and remediate.
- We ask that you give us a reasonable window to address the issue before any public disclosure.

## Scope

This policy covers repositories in this GitHub organization. For security concerns about Advantec client engagements or services, contact your Advantec engagement lead directly.

We appreciate the work of security researchers and will credit reporters in release notes where appropriate, unless you prefer to remain anonymous.
